# General Knowledge Layer

通用知识层，存储与具体项目无关的编程范式、标准规范、设计模式等基础知识。

## 目录说明

| 目录 | 用途 |
|------|------|
| `paradigms/` | 编程范式（OOP、FP、响应式等） |
| `standards/` | 编码标准与规范（代码风格、命名约定等） |
| `patterns/` | 设计模式（创建型、结构型、行为型） |
| `security/` | 安全最佳实践（OWASP、加密、认证授权） |
| `testing/` | 测试策略与方法（单元测试、集成测试、E2E） |
| `desktop/` | 桌面端通用知识（Electron、Tauri、Flutter Desktop） |

## 特性

- 自动同步：每周从上游知识源同步
- 通用性：内容不绑定特定项目，可跨项目复用
