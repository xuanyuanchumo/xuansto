## 决策仲裁日志 (置信度: 0.85 | 技术栈: 通用)

### 现象
多 Agent 对技术方案、优先级、实现路径产生分歧，需要仲裁机制快速决策。

### 根因
不同 Agent 基于不同上下文和偏好做出判断，缺少统一的决策优先级框架。

### 解决方案

```
仲裁规则（按优先级）：
1. 安全 > 性能 > 可维护性 > 开发效率
2. 显式约束 > 隐式偏好
3. 用户明确要求 > Agent 推断
4. 最新信息 > 历史信息
5. 多数一致 > 少数异议
```

```
决策记录格式：
- 决策ID: DEC-YYYYMMDD-NNN
- 冲突描述: [简述]
- 选项A vs 选项B
- 仲裁依据: [引用规则编号]
- 最终决策: [结论]
- 副作用: [已知影响]
```

### 验证
每次仲裁生成决策记录，定期回顾仲裁规则有效性。
