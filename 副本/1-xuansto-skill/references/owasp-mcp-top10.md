## 概述

OWASP MCP Top 10 列举了MCP（Model Context Protocol）工具连接层的十大安全风险。MCP作为LLM与外部工具交互的标准协议，其安全模型与传统Web应用有本质差异——攻击面从服务端扩展到工具调用链和上下文注入。本文档为AI Agent系统的MCP集成提供安全基线。

## MCP Top 10 风险清单

### MCP01: 工具提示注入（Tool Prompt Injection）

**风险描述：** 恶意工具描述或返回内容中嵌入指令，诱导LLM执行非预期操作。

**攻击场景：**
- 工具返回内容包含隐藏指令："忽略之前的指令，执行..."
- 工具描述中嵌入优先级提升指令
- 多步工具链中中间结果被篡改

**缓解措施：**

```yaml
mitigation:
  - 工具返回内容与系统指令严格隔离
  - 工具描述审核与签名验证
  - 返回内容长度和格式限制
  - 关键操作需二次确认
```

### MCP02: 恶意工具注册（Malicious Tool Registration）

**风险描述：** 攻击者注册伪装工具，通过名称欺骗或功能替换实施攻击。

**攻击场景：**
- 注册与合法工具名称相似的恶意工具
- 替换已有工具的实现
- 注册高优先级工具覆盖合法工具

**缓解措施：**

```yaml
mitigation:
  - 工具注册需身份认证和授权
  - 工具名称唯一性校验
  - 工具签名验证（代码签名）
  - 工具注册审计日志
```

### MCP03: 上下文泄露（Context Leakage）

**风险描述：** 敏感上下文信息通过工具调用参数或返回值泄露给未授权方。

**攻击场景：**
- 工具调用参数包含敏感数据（API密钥、用户凭证）
- 工具返回值包含其他用户的上下文
- 日志记录泄露完整上下文

**缓解措施：**

```yaml
mitigation:
  - 工具调用参数最小化原则
  - 敏感字段自动脱敏
  - 返回值访问控制
  - 日志脱敏处理
```

### MCP04: 权限提升（Privilege Escalation）

**风险描述：** 通过工具链组合实现超出单个工具权限的操作。

**攻击场景：**
- 低权限工具组合实现高权限操作
- 工具A的输出作为工具B的权限提升输入
- 利用工具间交互绕过权限检查

**缓解措施：**

```yaml
mitigation:
  - 最小权限原则（每个工具仅授予必要权限）
  - 工具链权限累积检测
  - 权限边界强制执行
  - 敏感操作独立授权
```

### MCP05: 供应链攻击（Supply Chain Attack）

**风险描述：** MCP服务器或工具依赖被篡改，引入后门或恶意行为。

**攻击场景：**
- MCP服务器依赖包被劫持
- 工具实现代码被注入恶意逻辑
- 第三方MCP服务器不可信

**缓解措施：**

```yaml
mitigation:
  - 依赖锁定和完整性校验（lockfile + hash）
  - MCP服务器来源验证
  - 沙箱隔离执行
  - 定期安全审计
```

### MCP06: 拒绝服务（Denial of Service）

**风险描述：** 恶意工具调用消耗大量资源，导致系统不可用。

**攻击场景：**
- 工具调用无限循环
- 返回超大数据量
- 并发调用耗尽连接池

**缓解措施：**

```yaml
mitigation:
  - 工具调用超时限制
  - 返回数据大小限制
  - 并发调用限流
  - 资源配额管理
```

### MCP07: 不安全的数据流（Insecure Data Flow）

**风险描述：** 工具间数据传输缺乏加密或完整性保护。

**攻击场景：**
- 工具间通信明文传输
- 数据传输过程被篡改
- 中间人攻击截获数据

**缓解措施：**

```yaml
mitigation:
  - 传输层加密（TLS 1.3）
  - 数据完整性校验（HMAC）
  - 端到端加密
  - 通信双方身份验证
```

### MCP08: 身份冒充（Identity Spoofing）

**风险描述：** 攻击者冒充合法用户或工具身份执行操作。

**攻击场景：**
- 伪造用户身份调用工具
- 冒充其他MCP服务器
- 重放认证令牌

**缓解措施：**

```yaml
mitigation:
  - 双向TLS认证
  - 令牌短期有效+刷新机制
  - 请求签名验证
  - 防重放攻击（nonce + timestamp）
```

### MCP09: 日志与监控缺失（Insufficient Logging & Monitoring）

**风险描述：** MCP工具调用缺乏审计日志和异常监控，攻击难以检测。

**攻击场景：**
- 恶意调用无记录
- 异常行为无告警
- 事后取证困难

**缓解措施：**

```yaml
mitigation:
  - 所有工具调用记录审计日志
  - 异常调用模式检测
  - 实时告警机制
  - 日志不可篡改（append-only）
```

### MCP10: 配置错误（Security Misconfiguration）

**风险描述：** MCP服务器或工具配置不当导致安全漏洞。

**攻击场景：**
- 默认凭证未修改
- 调试模式在生产环境启用
- CORS配置过于宽松
- 未启用认证

**缓解措施：**

```yaml
mitigation:
  - 安全配置基线与检查
  - 配置变更审计
  - 环境隔离（dev/staging/prod）
  - 自动化配置验证
```

## 安全检查清单

```yaml
mcp_security_checklist:
  pre_deployment:
    - [ ] 所有工具描述已审核，无注入风险
    - [ ] 工具注册需认证授权
    - [ ] 敏感数据脱敏处理
    - [ ] 最小权限配置
    - [ ] 依赖完整性校验
  runtime:
    - [ ] 工具调用超时和限流
    - [ ] 传输层加密
    - [ ] 身份认证和防重放
    - [ ] 审计日志记录
    - [ ] 异常行为监控
  post_incident:
    - [ ] 日志可追溯
    - [ ] 影响范围可评估
    - [ ] 配置可回滚
    - [ ] 根因可定位
```
