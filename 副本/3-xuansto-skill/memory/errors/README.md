# 错误记忆目录

本目录用于存储开发过程中遇到的错误及其解决方案。

## 目录结构

```
errors/
├── runtime/          # 运行时错误
├── compile/          # 编译错误
├── test/             # 测试错误
├── deployment/       # 部署错误
└── integration/      # 集成错误
```

## 错误记录格式

每个错误记录应包含以下内容：

```yaml
---
error_id: ERROR-001
error_type: 错误类型
severity: 严重程度（critical/high/medium/low）
created_at: 创建日期
resolved: 是否已解决
resolved_at: 解决日期
---
```

## 错误学习机制

1. **错误捕获**：自动捕获和记录错误
2. **根因分析**：分析错误的根本原因
3. **解决方案库**：建立解决方案知识库
4. **预防建议**：生成预防类似错误的建议

## 错误使用

Agent 在遇到类似错误时会自动参考历史记录，加速问题解决。
