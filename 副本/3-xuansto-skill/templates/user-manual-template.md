## 3. 安装说明

### 3.1 桌面端安装

#### Windows系统

**步骤1：下载安装包**
1. 访问官方网站：[网址]
2. 点击"下载"按钮
3. 选择Windows版本
4. 等待下载完成

**步骤2：运行安装程序**
1. 双击下载的安装包 `[产品名]_Setup.exe`
2. 如果出现用户账户控制提示，点击"是"

**步骤：**
1. 打开应用，点击"注册"按钮
2. 输入手机号码/邮箱地址

## 7. 常见问题

### 7.1 账号相关

#### Q1: 忘记密码怎么办？

**解答：**
1. 在登录页面点击"忘记密码"
2. 输入注册时的手机号/邮箱
3. 获取验证码并验证身份
4. 设置新密码
5. 使用新密码登录

#### Q2: 如何修改绑定的手机号？

**解答：**
1. 进入"设置 > 账号安全"
2. 点击"手机号"旁边的"修改"
3. 验证原手机号
4. 输入新手机号并验证
5. 完成修改

#### Q3: 账号被锁定怎么办？

**解答：**
账号可能因以下原因被锁定：
- 连续多次输入错误密码
- 违反用户协议

解决方法：
1. 等待30分钟后重试
2. 联系客服解锁

### 7.2 功能相关

#### Q4: 数据如何同步？

**解答：**
数据会自动同步到云端，条件：
- 已登录账号
- 网络连接正常
- 已开启同步功能

手动同步：点击"设置 > 同步 > 立即同步"

#### Q5: 如何导出数据？

**解答：**
1. 进入"设置 > 数据管理"
2. 点击"导出数据"
3. 选择导出格式（Excel/CSV/PDF）
4. 选择导出范围
5. 点击"导出"并保存文件

### 7.3 性能相关

#### Q6: 应用运行缓慢怎么办？

**解答：**
请尝试以下方法：
1. 清理应用缓存：设置 > 存储 > 清理缓存
2. 关闭后台运行的其他应用
3. 检查网络连接
4. 更新到最新版本
5. 重启应用或设备

#### Q7: 如何减少流量消耗？

**解答：**
1. 开启"省流模式"：设置 > 通用 > 省流模式
2. 仅在WiFi下自动下载更新
3. 关闭自动播放视频

### 7.4 其他问题

#### Q8: 如何联系客服？

**解答：**
- 在线客服：设置 > 帮助与反馈 > 在线客服
- 客服邮箱：support@example.com
- 客服电话：400-XXX-XXXX（工作时间：9:00-18:00）

#### Q9: 如何提交功能建议？

**解答：**
1. 进入"设置 > 帮助与反馈"
2. 点击"功能建议"
3. 填写建议内容
4. 提交反馈

## 8. 故障排查

### 8.1 常见错误代码

| 错误代码 | 含义 | 解决方案 |
|----------|------|----------|
| E001 | 网络连接失败 | 检查网络连接后重试 |
| E002 | 登录超时 | 重新登录 |
| E003 | 服务器错误 | 稍后重试或联系客服 |
| E004 | 参数错误 | 检查输入内容 |
| E005 | 权限不足 | 检查账号权限 |
| E006 | 文件格式不支持 | 使用支持的文件格式 |
| E007 | 存储空间不足 | 清理存储空间 |

### 8.2 故障排查流程

#### 问题：应用无法启动

**排查步骤：**

| 步骤 | 检查项 | 解决方案 |
|------|--------|----------|
| 1 | 系统版本是否满足要求 | 升级操作系统 |
| 2 | 是否有足够存储空间 | 清理存储空间 |
| 3 | 应用是否为最新版本 | 更新应用 |
| 4 | 是否有冲突软件 | 关闭冲突软件 |
| 5 | 重装应用 | 卸载后重新安装 |

#### 问题：无法登录

**排查步骤：**

| 步骤 | 检查项 | 解决方案 |
|------|--------|----------|
| 1 | 网络是否正常 | 检查网络连接 |
| 2 | 账号密码是否正确 | 确认或重置密码 |
| 3 | 账号是否被锁定 | 联系客服 |
| 4 | 服务器是否正常 | 查看公告或联系客服 |

#### 问题：数据同步失败

**排查步骤：**

| 步骤 | 检查项 | 解决方案 |
|------|--------|----------|
| 1 | 网络是否正常 | 检查网络连接 |
| 2 | 是否已登录 | 登录账号 |
| 3 | 同步功能是否开启 | 开启同步功能 |
| 4 | 存储空间是否充足 | 清理空间 |
| 5 | 手动触发同步 | 点击立即同步 |

### 8.3 日志收集

**如何收集日志用于问题诊断：**

1. 进入"设置 > 关于"
2. 连续点击版本号7次，开启开发者模式
3. 返回设置，进入"开发者选项"
4. 点击"导出日志"
5. 将日志文件发送给技术支持

### 8.4 重置应用

**警告：重置将清除所有本地数据**

**重置步骤：**
1. 进入"设置 > 存储"
2. 点击"清除数据"
3. 确认操作
4. 重新启动应用

**残留清理：**

**残留清理：**
- 配置文件：`~/Library/Application Support/[产品名]`
- 缓存文件：`~/Library/Caches/[产品名]`

- 日志文件：`~/Library/Logs/[产品名]`

### 自动更新说明

| 平台 | 更新机制 | 说明 |
|------|----------|------|
| Windows | 内置自动更新 | 后台下载，重启安装；支持增量更新 |
| macOS | Sparkle框架 / 内置更新 | 后台下载，提示重启；支持增量更新 |

**更新策略：**
- 检查频率：应用启动时 + 每4小时后台检查
- 更新通道：稳定版（Stable）、测试版（Beta）
- 回滚支持：保留上一版本安装包，支持一键回滚
- 增量更新：当更新包 < 10MB 时使用增量更新，否则全量更新

**手动检查更新：**
- 菜单栏：帮助 > 检查更新
- 快捷键：Ctrl+Shift+U (Windows/Linux) / Cmd+Shift+U (macOS)

### 常见桌面端问题排查

#### 问题1：Windows SmartScreen阻止启动

**现象：** 弹出"Windows已保护你的电脑"提示

**解决方案：**
1. 点击"更多信息"
2. 点击"仍要运行"
3. 此问题通常在代码签名后消除

#### 问题2：macOS提示"应用已损坏"

**现象：** 提示"[产品名]已损坏，无法打开"

**解决方案：**
```bash
# 方法一：移除隔离属性
xattr -cr /Applications/[产品名].app

# 方法二：允许任何来源（需谨慎）
sudo spctl --master-disable
```

#### 问题3：Linux下AppImage无法运行

**现象：** 双击AppImage无反应

**解决方案：**
```bash
# 检查执行权限
ls -la [产品名].AppImage

# 添加执行权限
chmod +x [产品名].AppImage

# 检查FUSE依赖
sudo apt install libfuse2  # Ubuntu/Debian
sudo dnf install fuse-libs  # Fedora

# 以调试模式运行查看错误
./[产品名].AppImage --appimage-help
```

#### 问题4：自动更新失败

**现象：** 更新下载失败或安装失败

**排查步骤：**
1. 检查网络连接是否正常
2. 检查磁盘空间是否充足（至少500MB可用）
3. 检查是否有杀毒软件拦截更新
4. 查看更新日志：帮助 > 打开日志目录
5. 手动下载最新版本覆盖安装

#### 问题5：窗口显示异常/白屏

**现象：** 应用窗口空白或渲染异常

**排查步骤：**
1. 尝试强制刷新：Ctrl+Shift+R / Cmd+Shift+R
2. 清除缓存：帮助 > 清除缓存并重启
3. 检查GPU加速：设置 > 高级 > 关闭硬件加速
4. 更新显卡驱动到最新版本
5. 以安全模式启动：`[产品名] --safe-mode`
