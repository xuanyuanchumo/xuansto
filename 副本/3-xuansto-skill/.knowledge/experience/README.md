# Experience Knowledge Layer

经验知识层，存储从实际开发过程中提取的错误修复、性能优化、安全加固等经验性知识。

## 目录说明

| 目录 | 用途 |
|------|------|
| `errors/` | 错误与异常经验（常见错误、调试技巧、修复方案） |
| `errors/desktop/` | 桌面端错误经验（原生崩溃、渲染异常等） |
| `patterns/` | 经验性模式（已验证的解决方案、最佳实践） |
| `performance/` | 性能优化经验（瓶颈分析、优化策略、基准测试） |
| `security/` | 安全加固经验（漏洞修复、安全审计、合规经验） |
| `integration/` | 集成经验（第三方服务、跨系统对接、数据迁移） |
| `desktop/` | 桌面端开发经验 |
| `desktop/build-fixes/` | 构建问题修复经验（编译错误、链接问题、依赖冲突） |
| `desktop/signing-issues/` | 签名问题经验（代码签名、证书管理、公证流程） |
| `desktop/platform-compatibility/` | 平台兼容性经验（Windows/macOS/Linux 差异处理） |
| `refactoring/` | 重构经验（代码重构记录、架构演进、技术债管理） |
| `decisions/` | 技术决策记录（ADR、方案选型、权衡分析） |

## 特性

- 自动提取：从开发过程中自动提取经验条目
- 审核机制：新经验条目需经审核后方可入库
- 置信度阈值：仅收录置信度 ≥ 0.8 的高质量经验
