# 指标记忆目录

本目录用于存储开发过程中的各类指标数据。

## 目录结构

```
metrics/
├── performance/      # 性能指标
├── quality/          # 质量指标
├── efficiency/       # 效率指标
├── reliability/      # 可靠性指标
└── security/         # 安全指标
```

## 指标类型

### 性能指标
- 响应时间
- 吞吐量
- 资源使用率
- 并发处理能力

### 质量指标
- 代码覆盖率
- 测试通过率
- 代码复杂度
- 技术债务

### 效率指标
- 开发速度
- 首次通过率
- 平均修复时间
- Agent调用成功率

### 可靠性指标
- 故障率
- 恢复时间
- 可用性
- 数据一致性

### 安全指标
- 漏洞数量
- 安全事件数
- 合规率
- 风险评分

## 指标记录格式

```yaml
---
metric_id: METRIC-001
metric_type: 指标类型
measurement_date: 测量日期
period: 统计周期
---
```
