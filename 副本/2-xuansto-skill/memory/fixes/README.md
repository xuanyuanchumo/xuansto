# 修复记忆目录

本目录用于存储问题修复的历史记录和最佳实践。

## 目录结构

```
fixes/
├── bug-fixes/        # Bug修复记录
├── hotfixes/         # 紧急修复记录
├── refactoring/      # 重构修复记录
└── optimization/     # 优化修复记录
```

## 修复记录格式

每个修复记录应包含以下内容：

```yaml
---
fix_id: FIX-001
fix_type: 修复类型
related_error: 相关错误ID
created_at: 创建日期
fixed_by: 修复者
verified: 是否已验证
---

## 修复学习机制

1. **修复记录**：自动记录所有修复操作
2. **方案复用**：相似问题复用历史修复方案
3. **风险评估**：评估修复的潜在风险
4. **最佳实践**：提炼修复最佳实践

## 修复使用

Agent 在修复问题时会自动参考历史修复记录，提高修复效率和质量。
