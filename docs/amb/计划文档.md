## 2. 核心要求（适用于全部文档）

- **严格基于代码事实**：所有分析、架构设计、问题点均须引用具体文件路径、代码片段、配置内容。
- **聚焦核心业务**：若项目庞大，优先关注直接影响运行的核心模块、关键逻辑与外部依赖。
- **统一输出格式**：Markdown 文档，含目录、表格、代码块、Mermaid 图表；图表需使用可渲染的 Mermaid 语法。
- **问题可追踪**：各文档发现的问题需统一编号（如 `ARCH-01`），最终汇总至问题清单。
- **渐进式加载披露** 指：特效或资源分阶段加载，先展示骨架屏/占位符，再逐步升级为低精度、高精度资源，最后激活交互，全程管理加载状态并提供反馈。

## 3. 任务流程（请严格按顺序执行）

### 阶段一：生成六份分析文档

#### 3.1 总体架构文档 (`ARCHITECTURE.md`)

**目标**：描绘当前架构、运行时流程与目标架构差异。

**内容大纲**：
- 项目概览（定位、核心能力、用户交互模式）
- 完整文件目录树（标注每个文件的用途）
- 当前架构分层
  - Skill 层：触发条件、参数、提示词
  - 执行层：脚本、工具调用、外部 API
  - 资源层：静态资源、模板、配置
  - 依赖层：外部 MCP/服务、环境依赖
- 调用流程图（Mermaid 序列图或流程图，从用户输入到最终输出）
- 目标架构设计
  - Skill 与 MCP 的职责划分
  - MCP Server 边界与接口
  - 渐进式加载的注入点与触发机制
- 当前架构 vs. 目标架构差异表（逐项对比）
- 风险与约束（平台限制、向后兼容、性能等）

#### 3.2 数据库 / 数据存储详细设计文档 (`DATABASE_DESIGN.md`)

**内容大纲**：
- 当前数据存储盘点（文件、环境变量、内存、数据库等）
- 所有持久化/缓存数据实体清单（含 JSON/YAML 示例）
- 数据生命周期（CRUD 时机与触发条件）
- 重构后数据模型
  - MCP Server 所需的状态/资源存储结构体定义
  - 渐进式加载相关字段（加载阶段、已加载列表、动画进度等）
  - ER 图或实体关系描述
- 数据迁移策略（旧格式 → 新模型）
- 存储技术选型建议（如需要）

#### 3.3 MCP 详细分析文档 (`MCP_REVIEW.md`)

**内容大纲**：
- 现有 MCP 调用盘点（工具、资源、配置）
- 可 MCP 化能力识别
  - 适合封装为 Tool 的功能单元（含输入输出说明）
  - 适合封装为 Resource 的数据（URI 模式、内容类型）
- 目标 MCP Server 设计
  - Server 名称、描述
  - Tool 列表（名称、描述、参数 JSON Schema、返回值）
  - Resource 列表（URI、描述、内容类型）
  - 权限与安全边界
  - `mcpServers` 配置 JSON 示例（优先 npx/uvx 方式）
- 渐进式加载与 MCP 的关联（工具负责加载，暴露状态/通知）
- Skill → MCP 交互协议（调用方式、参数传递、结果处理）

#### 3.4 Skill 详细分析文档 (`SKILL_REVIEW.md`)

**内容大纲**：
- Skill 定义文件全文解析（触发条件、参数、提示词、脚本引用）
- 功能逻辑分步拆解（从参数解析到最终输出，标注代码位置）
- 交互模式（单轮/多轮、输入输出格式）
- 特效逻辑分析（实现方式、加载方式、与渐进式目标的差距）
- 可复用模块清单 / 需废弃或重写部分
- 依赖图（文件调用链，Mermaid 图）

#### 3.5 API 接口详细分析文档 (`API_SPECIFICATION.md`)

**内容大纲**：
- 现有 API 调用清单
  - 内部 API（模块间调用）
  - 外部 API（HTTP、SDK 等，含请求方式、参数、返回值、认证）
- 接口依赖拓扑图（Mermaid）
- 重构后 API 设计
  - Skill ↔ MCP Server 的 Tool 调用协议
  - MCP Server 对外接口（如适用）
  - 渐进式加载相关接口（资源清单、进度上报、状态查询）
- 接口契约（请求/响应 Schema，版本管理建议）
- 异常处理、重试与降级方案

#### 3.6 整合重构迭代方案 (`REFACTOR_PLAN.md`)

**内容大纲**：
- 统一问题清单（合并前五份文档发现的问题，去重，标注影响域：Skill / MCP / 数据 / API / 特效 / 架构）
- 影响链分析（文件、模块、外部依赖的连锁影响）
- 优先级矩阵（紧急/高/中/低，标注依据）
- 模块化重构步骤（阶段拆分，每步输入/输出/验收标准/依赖）
- 渐进式加载披露实现方案（阶段设计、状态机、过渡动画、性能指标）
- 测试策略
  - 单元测试（MCP Tool、状态管理）
  - 集成测试（Skill-MCP 联动、特效加载流程）
  - 端到端测试（完整交互）
  - 回归验证方案
- 持续集成建议（Lint、Schema 校验、MCP 定义验证、构建流水线）
