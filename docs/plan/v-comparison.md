## 2. 标注说明

| 标注 | 含义 | 说明 |
|------|------|------|
| 🟢 新增 | 前一版本不存在，当前版本新引入 | 全新功能或能力 |
| 🔵 增强 | 相较前一版本功能增强或性能提升 | 已有能力的升级 |
| 🟡 不变 | 与前一版本保持一致 | 无变化 |
| 🔴 削弱 | 相较前一版本功能削弱或约束收紧 | 能力回退 |
| ⚫ 废弃 | 前一版本中存在但当前版本已移除 | 不再支持 |
