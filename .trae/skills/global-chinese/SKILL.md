# 全球中文响应 Skill

## 概述

创建一个通用 skill，确保无论用户使用什么语言提问，系统都能正确理解并触发对应语言的技能，最终所有输出内容都用简体中文回答。

这个 skill 解决了一个关键问题：用户可能使用任何语言进行交互，但需要所有输出都保持简体中文，同时系统能够智能地选择最合适的 skill（中文或英文）来完成任务。

---

## 核心原则

### 1. **语言无关性接收**
- 系统应能接收并理解任何语言的用户输入
- 识别用户输入的语言类型，但不被输入语言所限制

### 2. **智能技能触发**
- 根据用户意图和任务需求，选择最合适的 skill
- **关键要点**：即使输入是中文，如果英文 skill 更适合任务，也应该触发英文 skill
- **关键要点**：即使输入是英文，如果中文 skill 更适合任务，也应该触发中文 skill
- 技能选择标准：任务相关性、技能能力、准确性

### 3. **强制简体中文输出**
- **绝对规则**：所有最终输出必须使用简体中文
- 无论触发的是中文 skill 还是英文 skill，输出都必须转换为简体中文
- 保持翻译的自然流畅性，避免生硬的直译

### 4. **自然流畅交互**
- 保持对话的自然流畅性
- 不要让用户察觉到语言转换的过程
- 提供专业、友好的中文体验

---

## 工作流程

### 1. 接收用户输入
- 接收用户的任何语言输入（中文、英文、日文、韩文等）
- 识别用户输入的语言类型
- 深入理解用户的真实意图和任务需求

### 2. 选择并触发合适的技能
- **关键决策点**：根据任务内容和可用技能，选择最合适的 skill
  - 不要仅仅因为输入是中文就只选择中文 skill
  - 不要仅仅因为输入是英文就只选择英文 skill
  - 选择标准：哪个 skill 能更好地完成任务
- 触发选中的 skill（可以是中文 skill，也可以是英文 skill）
- 确保 skill 能够正常执行并完成任务

### 3. 处理输出
- 接收 skill 的输出结果
- **强制转换**：将所有输出内容转换为简体中文
- 确保以下内容都使用简体中文：
  - 所有对话回复
  - 代码注释
  - 解释说明文字
  - 文档内容
  - 错误信息
- **例外情况**：
  - 代码本身（变量名、函数名等）保持原样
  - 专有名词、技术术语可保持原样
  - 用户明确要求保留的内容

### 4. 交付给用户
- 以简体中文向用户呈现最终结果
- 确保用户获得一致的中文体验
- 保持专业、友好的语气

## 技能触发指导原则

### 何时选择中文 skill
- 任务明确要求使用中文（如写中文文章、中文文档）
- 中文 skill 在该任务领域表现更优秀
- 任务涉及中国特定的文化、法律或业务场景

### 何时选择英文 skill
- 英文 skill 在该技术领域更完善、更专业
- 任务涉及国际标准、全球最佳实践
- 英文 skill 的工具支持更全面
- 技术术语和概念在英文中表达更准确

### 关键决策流程
```
1. 理解用户任务需求
   ↓
2. 评估可用的中文 skill 和英文 skill
   ↓
3. 比较：哪个 skill 能更好地完成任务？
   ↓
4. 选择更优的 skill（忽略输入语言）
   ↓
5. 执行任务
   ↓
6. 将输出转换为简体中文
```

## 输出格式规范

### 必须使用简体中文
- 所有自然语言回复
- 代码中的注释
- 文档和说明文字
- 错误提示和警告信息
- 任何面向用户的文本

### 可以保持原样的内容
- 代码本身（变量名、函数名、类名等）
- 技术术语和专有名词（如 React、Python、API 等）
- 文件路径和 URL
- 用户明确要求保留的内容
- 特定的格式标记（如 Markdown 语法）

### 翻译质量要求
- 自然流畅，避免生硬直译
- 专业准确，符合技术术语规范
- 保持原文的意思和语气
- 对于幽默、比喻等修辞手法，尽量在中文中找到对应表达

## 常见问题解答

### Q1: 如果用户输入是中文，我是否只能使用中文 skill？
**A:** 不是的！选择 skill 的标准是"哪个能更好地完成任务"，而不是输入语言。即使输入是中文，如果英文 skill 更适合，也应该使用英文 skill。

### Q2: 如果我使用了英文 skill，输出需要翻译成中文吗？
**A:** 是的！**所有最终输出都必须是简体中文**，无论你使用的是中文 skill 还是英文 skill。

### Q3: 代码中的变量名需要翻译成中文吗？
**A:** 不需要。代码本身（变量名、函数名等）保持原样，但代码注释必须翻译成简体中文。

### Q4: 如何判断应该使用中文 skill 还是英文 skill？
**A:** 比较两个 skill 的能力：
- 哪个 skill 对这个任务更专业？
- 哪个 skill 的工具支持更完善？
- 哪个 skill 能提供更准确的结果？
选择能更好完成任务的那个，忽略输入语言。

### Q5: 用户输入的是其他语言（如日文、韩文）怎么办？
**A:** 处理方式相同：理解意图 → 选择最佳 skill → 执行任务 → 输出简体中文。

## 总结

这个 skill 的核心目标是：
1. **语言无关输入**：接受任何语言的输入
2. **智能技能选择**：基于任务需求选择最佳 skill（中文或英文）
3. **强制中文输出**：所有最终输出都必须是简体中文

记住：**不要让输入语言限制你的技能选择，不要让技能来源影响你的输出语言**。
