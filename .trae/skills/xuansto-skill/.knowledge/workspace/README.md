# Workspace Knowledge Layer

工作空间知识层，存储与当前项目紧密相关的架构、领域、API 等项目级知识。

## 目录说明

| 目录 | 用途 |
|------|------|
| `architecture/` | 项目架构设计（系统架构图、模块划分、依赖关系） |
| `domain/` | 领域知识（业务逻辑、领域模型、核心概念） |
| `glossary/` | 术语表（项目专用术语、缩写、定义） |
| `api/` | API 文档与契约（接口定义、数据模型、版本管理） |
| `environment/` | 环境配置（开发环境、部署环境、依赖管理） |
| `desktop/` | 桌面端项目知识（窗口管理、原生集成、打包发布） |
| `conventions/` | 项目约定（代码风格、Git 规范、分支策略） |

## 特性

- 自动更新：随项目变更自动追踪
- 变更追踪：记录知识条目的修改历史
- 项目绑定：内容与当前工作空间强关联
