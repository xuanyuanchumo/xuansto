## 4. API定义

### 4.1 端点列表

| 方法 | 路径 | 描述 | 认证要求 |
|------|------|------|----------|
| GET | /api/v1/resource | 获取资源列表 | 是 |

| GET | /api/v1/resource/{id} | 获取单个资源 | 是 |
| PUT | /api/v1/resource/{id} | 更新资源 | 是 |
| DELETE | /api/v1/resource/{id} | 删除资源 | 是 |

### 4.2 详细API规范

#### 4.2.1 获取资源列表

**请求**:
```http
GET /api/v1/resource?page=1&limit=20&sort=created_at
Authorization: Bearer <token>
```

**响应**:
```json
{
  "code": 200,
  "message": "success",
  "data": {
    "items": [],
    "pagination": {
      "page": 1,
      "limit": 20,
      "total": 100,
      "totalPages": 5
    }
  }
}
```

#### 4.2.2 创建新资源

**请求**:
```http
POST /api/v1/resource
Authorization: Bearer <token>
Content-Type: application/json

{
  "name": "资源名称",
  "description": "资源描述"
}
```

**响应**:
```json
{
  "code": 201,
  "message": "created",
  "data": {
    "id": "res_xxxxx",
    "name": "资源名称",
    "description": "资源描述",
    "createdAt": "2024-01-01T00:00:00Z"
  }
}
```
