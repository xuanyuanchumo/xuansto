# /status 命令

## 命令描述

`/status` 命令用于项目状态总览与健康检查，是项目运行态监控的核心命令。该命令管理从状态采集到健康评估的完整检查流程，实时展示当前Phase、活跃Agent、门禁通过率、Token消耗与知识库状态，支持简要概览与详细报告两种模式，确保项目运行状态的透明性与可控性。

---

## 触发条件

| 触发方式 | 说明 |
|----------|------|
| 命令输入 | 用户输入 `/status` |
| 关键词触发 | 用户提及"状态"、"概览"、"健康检查"、"项目状态" |
| 自动触发 | 每个Phase切换时自动输出简要状态 |
| 流程触发 | 关键门禁检查失败时自动触发状态报告 |

---

## 命令名称与语法

```
/status [options]
```

---

## 参数定义

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| --detail | string | 否 | brief | 详情级别：brief（简要）、full（完整） |
| --watch | boolean | 否 | false | 持续监控模式，定期刷新状态 |
| --watch-interval | number | 否 | 30 | 持续监控刷新间隔（秒） |
| --agent | string | 否 | all | 查看指定Agent状态 |
| --phase | boolean | 否 | false | 显示Phase详情 |
| --gates | boolean | 否 | false | 显示门禁详情 |
| --token | boolean | 否 | false | 显示Token消耗详情 |
| --kb | boolean | 否 | false | 显示知识库状态详情 |

---

## 示例用法

### 示例1: 简要状态

```bash
/status
```

输出项目简要状态概览。

### 示例2: 完整状态

```bash
/status --detail full
```

输出项目完整状态详细报告。

### 示例3: 持续监控

```bash
/status --watch
```

启用持续监控模式，每30秒刷新状态。

### 示例4: 自定义监控间隔

```bash
/status --watch --watch-interval 60
```

启用持续监控，每60秒刷新一次。

### 示例5: 查看特定详情

```bash
/status --detail full --gates --token
```

输出完整报告并重点展示门禁与Token详情。

---

## 质量门禁

| 门禁标识 | 阻塞级别(BLOCK/WARN) | 通过标准 |
|----------|----------------------|----------|
| STATUS-HEALTHY | WARN | 所有核心服务运行正常且无关键门禁失败 |

---

## 注意事项

1. **监控开销**: 持续监控模式会增加Token消耗，建议按需使用
2. **状态时效**: 状态数据为查询时刻快照，非实时数据
3. **健康评估**: 健康状态基于多维度指标综合评估
4. **风险提示**: 关注WARN级别的风险项，及时处理避免升级
5. **Token预算**: 定期检查Token消耗，避免超出预算
