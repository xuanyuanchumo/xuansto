# /help 命令

## 命令用途

显示当前阶段可用命令列表、命令用法说明和系统帮助信息。

## MCP工具调用链

| 顺序 | MCP工具 | 参数 | 说明 |
|------|---------|------|------|
| 1 | resource_load_status | action=status | 查询当前加载阶段 |

## 降级策略

| MCP工具 | 降级方式 | 降级脚本/操作 |
|---------|----------|---------------|
| resource_load_status | 内联执行 | 内联阶段判断 |

## 涉及Agent

| Agent | 角色 | 职责 |
|-------|------|------|
| orchestrator | 主导 | 帮助信息汇总与展示 |

## 命令描述

根据当前渐进式加载阶段，显示可用命令列表和使用说明。在SKELETON阶段即可使用，是用户获取系统帮助的首要入口。

## 触发条件

| 触发方式 | 说明 |
|----------|------|
| 命令输入 | 用户输入 `/help` |
| 别名触发 | `/h`, `/?` |
| 关键词触发 | 用户提及"帮助"、"help"、"怎么用"、"可用命令" |
| 条件触发 | 用户不确定可用命令时 |

## 命令名称与语法

```
/help [--phase=<阶段>] [--command=<命令名>]
```

## 参数定义

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `--phase` | enum | 否 | current | 查看阶段：current/all/skeleton/functional/enhanced/full |
| `--command` | string | 否 | — | 查看指定命令的详细帮助 |
| `--format` | enum | 否 | table | 输出格式：table/json/markdown |

## 执行流程

> 标准三步框架：1. 阶段检测 → 2. 命令筛选 → 3. 帮助展示

1. **阶段检测**：通过resource_load_status确认当前加载阶段
2. **命令筛选**：根据当前阶段筛选可用命令列表
3. **帮助展示**：格式化输出命令列表和用法说明

## 质量门禁

无特定质量门禁。该命令为查询类命令。

## 使用示例

### 示例1：查看当前可用命令

```
/help
```

### 示例2：查看指定命令帮助

```
/help --command=/init
```

### 示例3：查看所有阶段命令

```
/help --phase=all
```

### 示例4：JSON格式输出

```
/help --format=json
```
