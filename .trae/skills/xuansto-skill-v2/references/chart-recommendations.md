# 图表类型推荐数据库

> 版本: 3.0.0 | 更新日期: 2026-05-05 | 编码: UTF-8 | 行尾: LF

## 概述

本文件包含25种图表类型推荐，按用途分类（比较/趋势/分布/关系/流程）。每种图表包含使用场景、数据要求和框架实现提示。Agent应基于数据可视化需求按需搜索。

## 搜索策略

- 按数据用途关键词搜索（比较/趋势/分布/关系/流程）
- BM25排序权重：用途匹配(40%) + 数据结构匹配(35%) + 场景匹配(25%)
- 每次搜索返回Top 3图表类型供选择

## 比较（5种）

### 1. 柱状图 (Bar Chart)

| 属性 | 值 |
|------|-----|
| 使用场景 | 不同类别之间的数值比较 |
| 数据要求 | 分类数据 + 数值数据，类别≤12 |
| 框架实现提示 | D3: `d3.scaleBand()` + `d3.scaleLinear()`; Chart.js: `type: 'bar'`; ECharts: `type: 'bar'` |

**最佳实践**：
- 柱宽与间距比约1:1
- 数值轴从0开始
- 类别名称过长时使用水平柱状图

### 2. 分组柱状图 (Grouped Bar Chart)

| 属性 | 值 |
|------|-----|
| 使用场景 | 同一类别下多个子组的比较 |
| 数据要求 | 分类数据 + 多组数值数据，子组≤4 |
| 框架实现提示 | D3: 嵌套`scaleBand()`; Chart.js: 多dataset; ECharts: 多series + `type: 'bar'` |

**最佳实践**：
- 子组过多时考虑堆叠柱状图
- 使用一致的颜色编码
- 添加图例说明

### 3. 雷达图 (Radar Chart)

| 属性 | 值 |
|------|-----|
| 使用场景 | 多维度指标的综合比较（如能力评估） |
| 数据要求 | 3-8个维度 + 数值数据，比较对象≤5 |
| 框架实现提示 | D3: `d3.lineRadial()`; Chart.js: `type: 'radar'`; ECharts: `type: 'radar'` |

**最佳实践**：
- 维度过多时可读性下降
- 比较对象过多时颜色难以区分
- 适合展示"均衡性"而非精确值

### 4. 子弹图 (Bullet Chart)

| 属性 | 值 |
|------|-----|
| 使用场景 | 实际值与目标值的对比（KPI仪表盘） |
| 数据要求 | 实际值 + 目标值 + 范围区间 |
| 框架实现提示 | D3: 自定义实现; Chart.js: 插件; ECharts: `type: 'bar'` + markLine |

**最佳实践**：
- 适合Dashboard紧凑展示
- 使用颜色区分性能区间（优/良/差）
- 水平方向更易阅读

### 5. 词云 (Word Cloud)

| 属性 | 值 |
|------|-----|
| 使用场景 | 文本关键词频率可视化 |
| 数据要求 | 关键词 + 权重/频率，词数20-200 |
| 框架实现提示 | D3: `d3-cloud`库; Chart.js: 不支持; ECharts: `type: 'wordCloud'` + echarts-wordcloud |

**最佳实践**：
- 字体大小映射频率
- 颜色可映射类别或情感
- 交互时显示精确数值

## 趋势（5种）

### 6. 折线图 (Line Chart)

| 属性 | 值 |
|------|-----|
| 使用场景 | 数据随时间的变化趋势 |
| 数据要求 | 时序数据 + 数值数据，数据点≥5 |
| 框架实现提示 | D3: `d3.line()` + `d3.scaleTime()`; Chart.js: `type: 'line'`; ECharts: `type: 'line'` |

**最佳实践**：
- 数据点密集时使用采样或聚合
- 多条线时使用颜色+形状区分
- 添加交互tooltip显示精确值

### 7. 面积图 (Area Chart)

| 属性 | 值 |
|------|-----|
| 使用场景 | 趋势+量级展示，强调累积效果 |
| 数据要求 | 时序数据 + 数值数据 |
| 框架实现提示 | D3: `d3.area()`; Chart.js: `type: 'line', fill: true`; ECharts: `type: 'line', areaStyle: {}` |

**最佳实践**：
- 多系列时使用堆叠面积图
- 使用半透明填充避免遮挡
- 堆叠面积图注意数据顺序

### 8. 阶梯图 (Step Chart)

| 属性 | 值 |
|------|-----|
| 使用场景 | 离散事件/状态变化（如价格调整、开关状态） |
| 数据要求 | 时序数据 + 离散值变化点 |
| 框架实现提示 | D3: `d3.line().curve(d3.curveStep)`; Chart.js: `stepped: true`; ECharts: `step: 'middle'` |

**最佳实践**：
- 适合展示不连续变化
- 标注变化点原因
- 与折线图区分使用

### 9. K线图 (Candlestick Chart)

| 属性 | 值 |
|------|-----|
| 使用场景 | 金融数据开盘/收盘/最高/最低 |
| 数据要求 | 时序 + OHLC数据（开盘/最高/最低/收盘） |
| 框架实现提示 | D3: 自定义实现; Chart.js: `chartjs-chart-financial`; ECharts: `type: 'candlestick'` |

**最佳实践**：
- 红涨绿跌（中国市场）或绿涨红跌（国际市场）
- 添加成交量副图
- 支持缩放和拖拽

### 10. 桑基图 (Sankey Diagram)

| 属性 | 值 |
|------|-----|
| 使用场景 | 流量/能量/资源的流向与转化 |
| 数据要求 | 节点 + 连接 + 流量值 |
| 框架实现提示 | D3: `d3-sankey`库; Chart.js: 不支持; ECharts: `type: 'sankey'` |

**最佳实践**：
- 节点宽度映射总量
- 连接线宽度映射流量
- 颜色区分来源/去向

## 分布（5种）

### 11. 饼图 (Pie Chart)

| 属性 | 值 |
|------|-----|
| 使用场景 | 各部分占整体的比例 |
| 数据要求 | 分类数据 + 数值数据，类别≤6 |
| 框架实现提示 | D3: `d3.pie()` + `d3.arc()`; Chart.js: `type: 'pie'`; ECharts: `type: 'pie'` |

**最佳实践**：
- 类别过多时使用"其他"合并
- 标注百分比和数值
- 考虑用环形图替代更现代

### 12. 环形图 (Doughnut Chart)

| 属性 | 值 |
|------|-----|
| 使用场景 | 比例展示 + 中心可放汇总数据 |
| 数据要求 | 分类数据 + 数值数据，类别≤8 |
| 框架实现提示 | D3: `d3.arc().innerRadius()`; Chart.js: `type: 'doughnut'`; ECharts: `type: 'pie', radius: ['40%', '70%']` |

**最佳实践**：
- 中心区域展示汇总值
- 比饼图更现代美观
- 支持多环嵌套展示层级

### 13. 直方图 (Histogram)

| 属性 | 值 |
|------|-----|
| 使用场景 | 连续数据的频率分布 |
| 数据要求 | 连续数值数据，样本量≥30 |
| 框架实现提示 | D3: `d3.bin()` + `d3.scaleLinear()`; Chart.js: `type: 'bar'` + 预处理; ECharts: 自定义bin + `type: 'bar'` |

**最佳实践**：
- 合理选择bin宽度（Sturges/Freedman规则）
- Y轴显示频率或密度
- 可叠加正态分布曲线

### 14. 箱线图 (Box Plot)

| 属性 | 值 |
|------|-----|
| 使用场景 | 数据分布的中位数/四分位/异常值 |
| 数据要求 | 数值数据，样本量≥20 |
| 框架实现提示 | D3: 自定义实现; Chart.js: `@sgratzl/chartjs-chart-boxplot`; ECharts: `type: 'boxplot'` |

**最佳实践**：
- 适合多组数据分布对比
- 标注异常值
- 可与小提琴图结合

### 15. 小提琴图 (Violin Plot)

| 属性 | 值 |
|------|-----|
| 使用场景 | 数据分布的密度估计+箱线图 |
| 数据要求 | 数值数据，样本量≥30 |
| 框架实现提示 | D3: `d3.kernelDensity()` + 自定义; Chart.js: 插件; ECharts: 自定义实现 |

**最佳实践**：
- 比箱线图展示更多分布细节
- 适合对比多组数据分布形态
- 内嵌箱线图增加可读性

## 关系（5种）

### 16. 散点图 (Scatter Plot)

| 属性 | 值 |
|------|-----|
| 使用场景 | 两个变量之间的相关性 |
| 数据要求 | 两组数值数据（X/Y），数据点≥10 |
| 框架实现提示 | D3: `d3.scaleLinear()` + circle; Chart.js: `type: 'scatter'`; ECharts: `type: 'scatter'` |

**最佳实践**：
- 大数据量时使用透明度避免重叠
- 添加趋势线/回归线
- 标注异常点

### 17. 气泡图 (Bubble Chart)

| 属性 | 值 |
|------|-----|
| 使用场景 | 三维数据关系（X/Y/大小） |
| 数据要求 | 三组数值数据（X/Y/Size），气泡≤50 |
| 框架实现提示 | D3: circle + `r`映射; Chart.js: `type: 'bubble'`; ECharts: `type: 'scatter', symbolSize: function` |

**最佳实践**：
- 气泡大小映射需使用面积而非半径
- 避免气泡重叠过多
- 添加图例说明大小含义

### 18. 热力图 (Heatmap)

| 属性 | 值 |
|------|-----|
| 使用场景 | 矩阵数据的强度/密度可视化 |
| 数据要求 | 二维分类数据 + 数值（矩阵） |
| 框架实现提示 | D3: rect + 颜色映射; Chart.js: `chartjs-chart-matrix`; ECharts: `type: 'heatmap'` |

**最佳实践**：
- 选择合适的色彩方案（顺序/发散）
- 标注数值或使用tooltip
- 日历热力图适合时间维度

### 19. 树图 (Treemap)

| 属性 | 值 |
|------|-----|
| 使用场景 | 层级数据的占比与结构 |
| 数据要求 | 层级数据 + 数值（大小） |
| 框架实现提示 | D3: `d3.treemap()`; Chart.js: `chartjs-chart-treemap`; ECharts: `type: 'treemap'` |

**最佳实践**：
- 面积映射数值大小
- 颜色映射类别或第二维度
- 支持下钻交互

### 20. 力导向图 (Force-Directed Graph)

| 属性 | 值 |
|------|-----|
| 使用场景 | 网络关系/节点连接可视化 |
| 数据要求 | 节点列表 + 边列表 |
| 框架实现提示 | D3: `d3.forceSimulation()`; Chart.js: 不支持; ECharts: `type: 'graph', layout: 'force'` |

**最佳实践**：
- 节点大小映射重要度
- 边粗细映射关系强度
- 支持拖拽和缩放交互
- 大图使用聚类布局

## 流程（5种）

### 21. 漏斗图 (Funnel Chart)

| 属性 | 值 |
|------|-----|
| 使用场景 | 转化流程各阶段流失率 |
| 数据要求 | 有序阶段 + 数值（递减） |
| 框架实现提示 | D3: 梯形path; Chart.js: 插件; ECharts: `type: 'funnel'` |

**最佳实践**：
- 标注每阶段转化率
- 使用渐变色增强视觉效果
- 从上到下或从左到右

### 22. 瀑布图 (Waterfall Chart)

| 属性 | 值 |
|------|-----|
| 使用场景 | 增减变化对累计值的贡献 |
| 数据要求 | 增减项 + 数值（正/负） |
| 框架实现提示 | D3: 堆叠柱状图变体; Chart.js: 预处理 + `type: 'bar'`; ECharts: `type: 'bar', stack` + 透明辅助 |

**最佳实践**：
- 正值绿色，负值红色
- 连接线展示累计值变化
- 首尾柱标注总计

### 23. 甘特图 (Gantt Chart)

| 属性 | 值 |
|------|-----|
| 使用场景 | 项目任务时间排期与进度 |
| 数据要求 | 任务 + 开始时间 + 结束时间 + 进度 |
| 框架实现提示 | D3: 水平条形 + 时间轴; Chart.js: 不原生支持; ECharts: `type: 'custom'` + renderItem |

**最佳实践**：
- 任务按时间排序
- 区分计划/实际进度
- 标注里程碑节点
- 支持拖拽调整

### 24. 桑基图-流程 (Sankey Diagram - Process)

| 属性 | 值 |
|------|-----|
| 使用场景 | 多阶段流程的流量转化 |
| 数据要求 | 阶段节点 + 流量连接 |
| 框架实现提示 | D3: `d3-sankey`; Chart.js: 不支持; ECharts: `type: 'sankey'` |

**最佳实践**：
- 与趋势类桑基图相同实现
- 强调流程方向性
- 标注转化率

### 25. 旭日图 (Sunburst Chart)

| 属性 | 值 |
|------|-----|
| 使用场景 | 多层级数据的占比与结构 |
| 数据要求 | 多层级树形数据 + 数值 |
| 框架实现提示 | D3: `d3.partition()` + arc; Chart.js: 不支持; ECharts: `type: 'sunburst'` |

**最佳实践**：
- 比饼图展示更多层级
- 支持点击下钻
- 中心可展示当前层级信息
- 颜色映射类别或深度
