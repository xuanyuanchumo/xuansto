# Java 开发规范

## Core Points
- 命名约定：类PascalCase、方法/变量camelCase、常量UPPER_SNAKE_CASE、包名全小写
- 项目结构：分层架构(controller/service/repository/model)、Maven/Gradle标准目录
- 依赖管理：Spring Boot Starter优先、版本统一管理、最小依赖原则
- 测试规范：JUnit 5+Mockito、测试覆盖率≥80%、集成测试用@Testcontainers
- 安全规范：输入验证、SQL参数化、敏感数据加密、日志脱敏

## Applicable Scenarios
- Backend Developer Agent开发Java/Spring服务
- Code Reviewer Agent检查Java代码规范
- Java项目架构设计和依赖管理
