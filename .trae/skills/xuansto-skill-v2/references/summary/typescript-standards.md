# TypeScript/JavaScript 开发规范

## Core Points
- TypeScript命名：接口PascalCase(不加I前缀)、类型别名PascalCase、枚举PascalCase、变量camelCase
- 项目结构：src/按功能模块组织、index.ts控制导出、barrel文件适度使用
- 依赖管理：ESM优先、最小依赖、版本锁定(pnpm)
- 测试规范：Vitest/Jest、覆盖率≥80%、快照测试适度使用
- 前端框架规范：React函数组件+Hooks、Next.js App Router、状态管理最小化

## Applicable Scenarios
- Frontend Developer Agent开发TypeScript项目
- Fullstack Engineer Agent开发Node.js后端
- Code Reviewer Agent检查TypeScript代码规范
