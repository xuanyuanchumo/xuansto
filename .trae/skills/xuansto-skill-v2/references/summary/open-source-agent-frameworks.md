# 开源Agent框架概览参考文档

## Core Points
- 综述10个主流开源AI Agent框架：AG2/AutoGen、CrewAI、LangGraph、BeeAI、Dapr Agents、AgentScope、LightAgent、Animus、ChatDev/MetaGPT、OpenAI Agents SDK
- 框架对比维度：核心范式、多Agent支持、状态管理、工具集成、生产就绪度
- AG2/AutoGen：对话驱动多Agent，支持人类代理；CrewAI：角色定义式，简洁易用
- LangGraph：图状态机，灵活编排；OpenAI Agents SDK：官方SDK，工具调用原生支持
- 为xuansto多Agent系统设计提供技术选型参考

## Applicable Scenarios
- 多Agent系统技术选型和架构设计
- 参考开源框架的最佳实践和设计模式
- 评估不同框架的适用场景和集成难度
