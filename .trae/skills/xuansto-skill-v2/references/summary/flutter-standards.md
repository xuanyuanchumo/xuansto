# Flutter/Dart 开发规范

## Core Points
- 命名规范：类UpperCamelCase、方法lowerCamelCase、常量lowerCamelCase(Dart惯例)、文件snake_case
- 项目结构：lib/下按功能模块组织、models/services/widgets/screens分层
- 代码规范：首选const构造函数、级联操作符、空安全、避免动态类型
- 测试规范：单元测试(test/)、Widget测试、集成测试(integration_test/)
- 桌面端特定：窗口管理、Platform Channel、键盘快捷键、拖拽支持

## Applicable Scenarios
- Mobile Developer Agent开发Flutter应用
- Desktop Developer Agent开发Flutter桌面端
- Flutter项目代码规范检查和审查
