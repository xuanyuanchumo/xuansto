# create-sddwcc SDD+TDD 多Agent架构参考文档

## Core Points
- 基于SDD(规格驱动开发)与TDD(测试驱动开发)融合的多Agent协作架构
- 18个专业化Agent分三层：规划层(需求/架构/测试规划)、执行层(编码/测试/重构)、验证层(审查/安全/合规)
- 核心框架definition-done确保每个阶段有明确的完成定义
- 通过MCP集成实现从需求到交付的全生命周期自动化

## Applicable Scenarios
- 参考SDD+TDD融合架构设计多Agent协作流程
- 实现规格驱动和测试驱动的开发方法论
- 设计阶段完成定义和质量保障机制
