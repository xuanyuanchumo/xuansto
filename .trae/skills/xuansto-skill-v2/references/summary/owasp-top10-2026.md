# OWASP Top 10 2026 参考文档

## Core Points
- Web应用最关键安全风险的权威列表，2025/2026版强化供应链安全和设计安全
- 十大风险：访问控制失效、加密失败、注入、不安全设计、安全配置错误、脆弱过时组件、认证失败、数据完整性失败、日志监控不足、服务端请求伪造
- 与OWASP Agentic Top 10形成互补，覆盖传统Web安全和AI/LLM集成安全
- 强化方向：SBOM要求、Secure by Design原则、云原生安全配置

## Applicable Scenarios
- Security Auditor Agent执行Web安全合规检查
- Code Reviewer Agent检查代码安全漏洞
- 设计安全编码规范和防护措施
