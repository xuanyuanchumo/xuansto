# Claude Code Collective 集成参考文档

## Core Points
- Claude Code Collective核心特性：TDD强制执行(RED→GREEN→REFACTOR)、Context7实时文档集成、智能任务路由
- TDD三阶段：RED(编写失败测试，禁止写实现)→GREEN(最小代码通过测试)→REFACTOR(重构优化，测试必须持续通过)
- Context7实时文档集成：自动获取最新API文档和库版本信息，减少过时API使用
- 智能任务路由：基于任务类型、复杂度和Agent能力自动分配任务

## Applicable Scenarios
- 实现TDD强制执行流程和质量保障
- 集成实时文档查询减少API使用错误
- 设计智能任务路由和Agent调度策略
