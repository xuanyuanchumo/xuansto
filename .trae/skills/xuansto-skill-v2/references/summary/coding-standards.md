# 编码规范参考文档

## Core Points
- 命名规范：有意义/一致性/可搜索三原则，变量camelCase、常量UPPER_SNAKE_CASE、类PascalCase、包kebab-case
- 代码风格：缩进2/4空格、行宽120、花括号同行、链式调用换行
- 注释规范：公共API必须文档注释、注释语言与团队一致、避免冗余注释、TODO标记格式
- 文件编码：统一UTF-8 without BOM、行尾LF、文件末尾换行

## Applicable Scenarios
- Code Reviewer Agent执行编码规范检查
- 项目初始化时建立编码规范基线
- Compliance Reviewer Agent验证代码风格合规性
