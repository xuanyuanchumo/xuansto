# 验收标准参考文档

## Core Points
- 验收标准（AC）定义用户故事完成条件，支持Given-When-Then(Gherkin)、检查清单、表格三种格式
- 编写遵循INVEST原则（独立/可协商/有价值/可估算/足够小/可测试）和SMART原则
- DoD（Definition of Done）分组织级/产品级/团队级/故事级四层，确保增量可发布
- 验收流程：开发完成→自测→Code Review→QA测试→UAT验收→验收完成
- 非功能性验收涵盖性能、安全、可用性、兼容性、可访问性五个维度

## Applicable Scenarios
- 编写用户故事验收标准和DoD检查清单
- 设计验收流程和验收报告模板
- 定义非功能性需求的具体衡量标准
