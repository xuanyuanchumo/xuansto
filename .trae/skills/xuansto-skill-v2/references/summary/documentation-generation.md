# 文档站点生成参考文档

## Core Points
- 两大文档框架：Docusaurus(React生态/功能丰富)和MkDocs(Python生态/轻量简洁)
- API文档自动生成：OpenAPI/Swagger规范、TypeDoc(TypeScript)、Sphinx(Python)
- Changelog自动化：conventional-commits规范、standard-version/commitizen工具链
- 与xuansto集成：Documentation Engineer Agent使用文档框架生成项目文档站

## Applicable Scenarios
- Documentation Engineer Agent搭建项目文档站
- 自动生成API文档和Changelog
- 选择合适的文档框架和工具链
