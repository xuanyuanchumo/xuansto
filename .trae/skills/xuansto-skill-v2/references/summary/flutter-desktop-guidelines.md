# Flutter Desktop Development Guidelines

## Core Points
- 核心主题：窗口管理、Platform Channels、桌面插件开发、构建配置、桌面UI模式、安全考虑
- 窗口管理：多窗口支持、窗口大小/位置控制、全屏模式
- Platform Channels：MethodChannel/EventChannel通信、自定义平台通道
- 构建配置：Windows/macOS/Linux三平台构建、代码签名、安装包生成

## Applicable Scenarios
- Desktop Developer Agent开发Flutter桌面应用
- Native Module Developer Agent实现平台通道和原生集成
- 跨平台桌面应用构建和发布
