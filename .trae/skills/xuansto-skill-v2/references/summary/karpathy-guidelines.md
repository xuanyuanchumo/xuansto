# Karpathy Guidelines 参考文档

## Core Points
- 源自Andrej Karpathy的软件开发经验，特别适用于AI辅助开发场景
- 四条核心准则：Think Before Coding(编码前思考)、Simplicity First(简洁优先)、Surgical Changes(外科手术式修改)、Goal-Driven Execution(目标驱动执行)
- Think Before Coding：澄清歧义再动手、确保每步有验证标准、不做过度设计
- Simplicity First：不添加未要求功能、不过度抽象、信任类型系统
- Surgical Changes：只修改必要代码、保持现有风格、不重构无关代码

## Applicable Scenarios
- 所有Agent遵循的行为准则基线
- Code Reviewer Agent检查代码变更是否符合准则
- 新Agent设计时参考行为规范
