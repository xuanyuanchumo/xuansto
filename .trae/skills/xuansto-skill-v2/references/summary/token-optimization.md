# Token消耗优化体系

## Core Points
- SKILL.md精简加载策略：渐进式加载、按需引用、摘要优先
- 按需加载策略：懒加载参考文档、工具定义延迟加载、Agent详情按需获取
- Token预算门禁：每阶段Token预算限制、超预算触发降级、实时监控消耗
- 上下文压缩增强：关键信息保留优先级、冗余检测与消除、压缩前持久化
- Token消耗监控指标：消耗率、预算利用率、压缩比、降级触发次数

## Applicable Scenarios
- Token Optimizer Agent优化Token使用效率
- 配置渐进式加载和按需加载策略
- 实现上下文压缩和Token预算管理
