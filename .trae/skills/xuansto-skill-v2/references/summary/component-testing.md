# UI组件开发与视觉回归测试参考文档

## Core Points
- 三大工具链集成：Storybook组件开发、Chromatic视觉回归测试、Playwright组件测试
- Storybook 8.x配置：Story文件自动生成、ArgsTable交互文档、Controls参数面板、Viewport响应式预览
- Chromatic视觉回归：自动截图对比、变更阈值可配、支持组件级和页面级快照
- Playwright组件测试：组件挂载测试、交互行为测试、可访问性测试集成

## Applicable Scenarios
- Frontend Developer Agent搭建组件开发和测试环境
- 实现视觉回归测试和组件级自动化测试
- 配置Storybook文档站和Chromatic CI集成
