# 并发任务执行规范

## Core Points
- 任务级并发：max_concurrent_agents=3，优先级加权调度，支持高优先级抢占
- Token预算分配：按Agent优先级和任务复杂度分配，实时监控消耗，80%预警100%强制结束
- 上下文隔离：每个Agent独立工作记忆缓冲区，共享只读项目上下文，写入需获取锁
- 知识库写入冲突：乐观锁+版本号机制，冲突时合并或回滚，保证一致性
- 系统级并发：全局最大10个并发Agent，超出进入FIFO等待队列

## Applicable Scenarios
- Orchestrator设计并发调度和资源分配策略
- 实现Agent间上下文隔离和知识库并发写入
- 配置并发限制和抢占机制
