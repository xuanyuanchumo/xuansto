# OWASP MCP Top 10 安全风险参考文档

## Core Points
- MCP工具连接层十大安全风险，攻击面从服务端扩展到工具调用链和上下文注入
- MCP01-MCP10：工具提示注入、工具权限越权、上下文污染、供应链攻击、凭证泄露、数据外泄、拒绝服务、协议降级、日志注入、资源耗尽
- MCP安全模型与传统Web应用有本质差异，需专门的安全基线
- 为AI Agent系统的MCP集成提供安全参考

## Applicable Scenarios
- Security Auditor Agent审查MCP集成安全性
- 配置MCP工具的安全策略和权限控制
- 设计MCP服务器的安全防护措施
