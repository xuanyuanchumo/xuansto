# Agentic安全框架集成指南

## Core Points
- 收录4大Agentic安全框架：Maris(策略引导防护)、SAFEFLOW(协议级IFC)、SAGA(治理安全架构)、Project CodeGuard(模型无关安全)
- Maris提供Policy-as-Code范式，控制Agent间通信和Agent-环境交互，集成到Runtime Supervisor运行时防护
- SAFEFLOW提供信息流控制(IFC)+事务回滚，集成到故障恢复和状态管理安全
- SAGA提供加密令牌+形式化验证，集成到Compliance Officer治理和审计追踪
- 完整定义OWASP ASI01-ASI10风险分类与防护策略映射，含TrinityGuard三层20种风险和SafeAgents评估方法论

## Applicable Scenarios
- 选择和集成Agentic安全框架
- 实现OWASP ASI风险防护策略
- 设计Agent安全评估和审计体系
