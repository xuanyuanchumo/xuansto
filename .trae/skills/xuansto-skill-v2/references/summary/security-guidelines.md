# 安全指南参考文档

## Core Points
- 安全编码实践：输入验证、输出编码、参数化查询、最小权限原则
- 常见漏洞防护：SQL注入、XSS、CSRF、路径遍历、SSRF的检测和防护方法
- 敏感数据处理：加密存储、传输加密(TLS 1.3)、密钥管理、日志脱敏
- 桌面端安全规范：Electron/Tauri安全配置、IPC安全、自动更新签名验证
- Agentic安全规范：OWASP Agentic Top 10 2026防护、Agent间通信安全、自主决策约束

## Applicable Scenarios
- Security Auditor Agent执行安全审查和合规检查
- Code Reviewer Agent检查安全编码实践
- 桌面应用安全配置和Agentic安全防护
