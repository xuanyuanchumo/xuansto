# CangjieSkills DocFlow 知识蒸馏集成参考文档

## Core Points
- CangjieSkills DocFlow是面向AI Agent的结构化知识蒸馏流程，目标降低60%以上Token消耗
- 四阶段流程：文档解析(格式标准化)→知识提取(实体关系识别)→结构化蒸馏(冗余消除/摘要生成)→技能知识库(索引构建/向量化)
- 替代低效的原始文档检索模式，保持知识完整性前提下实现Token优化
- 与xuansto集成：Token Optimizer Agent参考蒸馏流程优化上下文加载

## Applicable Scenarios
- 优化知识库Token消耗和检索效率
- 设计文档到结构化技能知识库的蒸馏流程
- 实现按需加载和上下文压缩策略
