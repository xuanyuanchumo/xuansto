### 对于API集成方

如果你通过API对接本系统，请注意以下变更：

#### 认证方式变更（重要⚠️）

```http
# ❌ 旧方式 (已废弃)
Authorization: Basic xxx

# ✅ 新方式 (必须使用)
Authorization: Bearer eyJhbGciOiJIUzI1NiIs...
```

**获取Token方式**:
```bash
curl -X POST https://api.example.com/api/v1/auth/login \
  -H "Content-Type: application/json" \
  -d '{"phone":"13800138000","password":"your_password"}'

# 返回:
# {"code":0,"data":{"token":{"accessToken":"eyJ...","refreshToken":"eyJ..."}}}
```

#### 接口变更摘要

| 接口 | 变更类型 | 说明 |
|------|----------|------|
| `POST /api/v1/auth/login` | 新增 | JWT登录接口 |
| `POST /api/v1/auth/register` | 新增 | 注册接口 |
| `POST /api/v1/auth/refresh` | 新增 | Token刷新接口 |
| `GET /api/v1/users/me` | 新增 | 获取当前用户信息 |
| `GET /api/v1/users` | ⚠️ 废弃 | 将在v2.0移除，改用search接口 |
| `POST /api/v1/orders` | 增强 | 新增优惠券参数 |
| `POST /api/v1/payments/create` | 新增 | 统一支付接口 |

详细的API文档请参考: [API Reference](https://api.example.com/swagger-ui.html)
