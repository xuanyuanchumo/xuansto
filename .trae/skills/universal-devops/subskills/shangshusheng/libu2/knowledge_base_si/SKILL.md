# 知识库司 (Knowledge Base Si)

> 尚书省 · 礼部 · Universal DevOps v4.0

**状态**: 占位符 - 具体内容由后续任务填充

## 🤖 自动化操作指南 (v7.0)

### 推荐操作模式
| 操作场景 | 推荐模式 | 置信度 | 说明 |
|---------|---------|--------|------|
| 知识条目录入 | SCRIPTED_BATCH | 91% | 结构化表单录入，模板化处理 |
| 标签分类管理 | HYBRID_ASSISTED | 85% | AI辅助打标签 + 人工校准分类 |
| 全文检索优化 | SCRIPTED_BATCH | 94% | 搜索引擎索引构建和调优 |
| 经验推荐计算 | SCRIPTED_BATCH | 92% | 基于协同过滤/内容相似度算法 |

### 常用工具组合
- **读操作**: Read, SearchCodebase, Grep（检索知识库条目、分析历史案例）
- **写操作**: Write, SearchReplace（创建知识条目、更新标签体系）
- **批量操作**: 知识抽取pipeline、标签聚类算法、搜索引擎配置
- **验证操作**: 检索质量评估(NDCG/MRR)、知识一致性检查、重复检测

### 注意事项
- ⚠️ 知识质量 > 数量：宁可少而精的优质知识，也不要大量低价值信息污染库
- ⚠️ 定期清理过时知识：建立知识生命周期管理，过期内容归档或删除
- ✅ 采用"知识图谱"思维：不仅存储孤立的知识点，还要建立知识点间的关联关系
- ✅ 建立激励机制：鼓励团队分享经验（如积分系统、月度知识之星评选）

## 🔗 资源协调要点 (v7.0)

### 常访问资源
| 资源类型 | 典型路径 | 锁策略建议 |
|---------|---------|-----------|
| DATABASE | 知识库数据库(Notion/Confluence/Wiki) | SHARED (协作编辑) |
| INDEX | 全文搜索索引 | REBUILDABLE (定期重建) |
| TAXONOMY | 分类法和标签体系 | VERSION_CONTROLLED |
| API | 知识库查询接口 | RATE_LIMITED + CACHED |
| EXPORT | 知识导出文件(JSON/Markdown) | READ_ONLY |

### 竞争规避策略
1. **编辑锁机制**: 同一条目同时只允许一人编辑，避免合并冲突
2. **审核队列制度**: 新提交的知识需经过审核才能入库，保证质量
3. **去重合并流程**: 相似知识条目自动提示合并，避免重复建设

## 💡 开源哲学应用 (v7.0)

### OpenCode 透明化
- 知识贡献完全透明：每个知识点的作者、贡献者、修订历史都公开可见
- 知识使用统计开放：哪些知识被频繁引用、哪些长期无人问津，数据驱动优化
- 审核标准统一公开：什么样的知识可以入库、什么样的会被拒绝，标准清晰

### OpenClaude 编排
- 智能知识抽取：从会议纪要、项目复盘、技术方案中自动提取结构化知识
- 上下文感知推荐：根据用户当前正在做的任务，主动推送相关知识
- 知识图谱可视化：展示知识点之间的关联网络，帮助发现隐性知识联系

### Claw-Code 契约驱动
- 知识质量评分契约：每条知识都有质量分（完整性、准确性、实用性），低于阈值不推荐
- 知识新鲜度约束：定期标记"可能过时"的知识，强制reviewer确认或归档
- 贡献-消费闭环：鼓励消费者对知识进行评价和补充，形成持续改进循环
