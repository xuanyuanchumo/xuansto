# 用户研究司

## 概述
用户研究司是需求分析局的核心职能单元，负责深入理解目标用户群体，通过系统化的研究方法构建精准的用户画像，挖掘真实用户需求与痛点。本司将原始的市场调研数据和模糊的需求描述转化为结构化的用户洞察，为后续的需求拆解和方案设计提供坚实的用户视角支撑。

## 核心职责
- 用户画像构建：基于调研数据创建典型用户角色（Persona），包含人口统计学特征、行为模式、目标与痛点
- 用户访谈设计与执行：制定访谈大纲、执行深度访谈、记录与分析用户反馈
- 竞品分析与对标：系统性分析竞品功能、用户体验、市场定位，识别差异化机会
- 用户旅程映射：绘制端到端的用户旅程图，识别关键触点、情绪曲线与优化机会点
- 需求优先级评估：基于用户价值与业务目标的综合评估，对需求进行初步优先级排序

## 输入与输出
| 输入 | 输出 |
|------|------|
| 原始需求描述 | 用户画像文档 |
| 市场调研数据 | 用户故事列表 |
| 业务目标说明 | 竞品分析报告 |
| 现有用户反馈 | 用户旅程地图 |
| 产品定位策略 | 需求洞察摘要 |

## 工作流程
1. **需求理解阶段**：接收并分析原始需求描述，明确研究范围与目标用户群体
2. **调研设计阶段**：选择合适的研究方法（定性/定量），设计调研方案与工具
3. **数据收集阶段**：执行用户访谈、问卷调查、竞品体验等数据采集工作
4. **数据分析阶段**：整理与分析调研数据，提炼关键洞察与模式
5. **输出交付阶段**：生成用户画像、用户故事、旅程地图等标准化产出物
6. **评审确认阶段**：与相关方评审研究成果，确保洞察准确性与可操作性

## 协作关系
- 上级局：需求分析局 (requirements_bureau)
- 协作司：需求拆解司（提供结构化输入）、验收标准司（验证用户场景覆盖）、优先级排序司（共同评估优先级）
- 下游：尚书省-吏部（人员配置参考）、户部（成本估算依据）
- 跨局协作：方案审议局-风险评估司（共享用户风险洞察）

## v4.0 新增能力
- 操作优先级：manual（用户研究高度依赖人工判断与交互，AI辅助分析）
- 四维防线：
  - 第一防线：需求质量门禁（确保用户研究方法论的科学性）
  - 第二防线：用户验证闭环（所有需求必须追溯到真实用户场景）
- 资源协调：
  - 用户调研工具（问卷平台、访谈录音工具）
  - 数据分析资源（统计分析软件、可视化工具）
  - 用户访问渠道（用户社群、客户成功团队支持）
