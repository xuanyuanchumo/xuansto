# 文档标准司

## 概述
文档标准司负责建立项目文档的全生命周期管理体系，包括文档分类标准、撰写模板、格式规范与版本管理策略。本司确保每一类文档都有明确的模板参照和质量要求，使团队成员能够高效产出高质量的技术文档，同时保障文档的可查找性、可维护性与时效性。

## 核心职责
- 文档模板制定：为 PRD、设计文档、API 文档、运维手册等常见文档类型设计标准模板
- 格式规范定义：统一 Markdown 结构、图表规范、术语表、引用格式
- 版本管理策略：确定文档的存储位置、版本控制方式与发布流程
- 文档索引维护：构建项目文档地图（Documentation Map），支持快速导航
- 质量基线设定：定义各类文档的最小必要内容与评审标准

## 输入与输出
| 输入 | 输出 |
|------|------|
| 项目类型与技术栈 | 文档标准指南 |
| 组织文档资产 | 模板库索引 |
| 团队协作模式 | 文档目录结构规范 |
| 合规性要求 | 版本管理策略文档 |
| 用户角色画像 | 文档受众矩阵 |

## 工作流程
1. **现状盘点阶段**：梳理现有文档资产，识别缺失类型与质量问题
2. **分类体系设计**：按用途（设计/开发/测试/运维）和受众（内部/外部）进行文档分类
3. **模板开发阶段**：为每类核心文档创建标准化 Markdown 模板
4. **格式规范编写**：定义标题层级、列表样式、代码块、表格、图片等的统一用法
5. **工作流设计**：明确文档的创建、评审、发布、归档全流程
6. **工具选型与配置**：选择文档平台（Wiki/GitBook/MkDocs）并进行初始化配置
7. **培训与推广**：向团队宣贯文档标准，提供快速上手指南

## 协作关系
- 上级局：规范制定局 (standards_bureau)
- 协作司：命名约定司（文档命名规范）、Lint 规则司（文档 Lint 规则）
- 下游：尚书省全体（文档撰写执行者）
- 跨局协作：需求分析局-用户研究司（用户文档需求输入）

## v4.0 新增能力
- 操作优先级：script（可使用脚本从模板库快速生成新文档骨架，自动化目录结构校验）
- 四维防线：
  - 第一防线：模板合规性检查（新建文档必须基于标准模板）
  - 第二防线：链接有效性扫描（自动检测文档中的失效链接）
  - 第三防线：文档 freshness 监控（标记长期未更新的关键文档）
- 资源协调：
  - 文档生成平台（MkDocs/GitBook/VitePress/Docusaurus）
  - 模板引擎（支持变量占位符的模板系统）
  - 文档 Lint 工具（markdownlint/vale 等）
  - 文档搜索索引（Algolia/Meilisearch 集成）
