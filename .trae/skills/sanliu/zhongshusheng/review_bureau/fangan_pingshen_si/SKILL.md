# 方案评审司

## 概述
方案评审司是中书省方案审议局的核心把关职能单元，负责对提交的技术方案进行系统性、多维度的专业评审。本司通过建立结构化的评审框架与检查清单，从技术可行性、架构合理性、成本效益、实施风险等角度全面审视方案质量，确保进入实施阶段的技术方案具备充分的论证基础与可执行性。

## 核心职责
- 技术方案评审：组织并执行技术设计文档、实施方案的结构化评审
- 可行性验证：从技术、资源、时间维度验证方案的落地可能性
- 成本效益分析：评估方案的人力成本、基础设施投入与预期收益
- 评审结论输出：给出通过 / 有条件通过（需修改） / 拒绝的明确决定
- 评审知识沉淀：将评审中发现的共性问题和最佳实践纳入评审知识库

## 输入与输出
| 输入 | 输出 |
|------|------|
| 技术方案文档 | 评审报告 |
| 架构设计文档 | 通过/修改/拒绝决定书 |
| 成本估算数据 | 评审意见清单 |
| 实施计划草案 | 风险提示与缓解建议 |
| 相关 ADR 记录 | 方案优化建议 |

## 工作流程
1. **材料预审阶段**：检查方案文档的完整性与格式合规性，不满足要求则退回补充
2. **评审组组建**：根据方案领域邀请相关技术专家组成评审委员会
3. **评审准备阶段**：分发评审材料，各评委提前阅读并准备评审意见
4. **评审会议召开**：由方案作者陈述，评委提问与讨论，记录关键意见
5. **综合评议阶段**：汇总各方意见，形成统一的评审结论与修改建议
6. **报告撰写阶段**：输出正式评审报告，明确结论与后续行动项
7. **闭环跟踪**：跟踪修改类方案的修订情况，确认后关闭评审流程

## 协作关系
- 上级局：方案审议局 (review_bureau)
- 协作司：风险评估司（风险维度输入）、影响分析司（变更影响评估）、决策记录司（结论归档）
- 下游：尚书省-工部（方案执行）、户部（预算审批依据）
- 跨局协作：需求分析局-优先级排序司（ROI 数据交叉参考）

## v4.0 新增能力
- 操作优先级：manual + script（核心评审依赖专家判断，辅助脚本生成评审检查清单与报告模板）
- 四维防线：
  - 第一防线：准入门槛检查（自动校验方案文档必须包含的最小内容集）
  - 第二防线：评审覆盖度保障（确保每个评审维度都有明确的评审意见）
  - 第三防线：决策可追溯性（评审结论必须关联具体评审意见与投票记录）
- 资源协调：
  - 评审专家库（按领域分类的技术专家名单）
  - 评审模板库（不同类型方案对应的评审检查清单）
  - 评审会议系统（在线协作评审工具）
  - 决策日志系统集成（重大评审结论需同步至 Decision Log）
