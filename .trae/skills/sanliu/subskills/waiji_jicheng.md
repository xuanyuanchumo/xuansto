# 外部技能集成指导

## 外部技能发现流程

### 1. 扫描机制

外部技能通过以下方式进行发现和识别：

1. **目录扫描**
   - 扫描 `.trae/skills/` 目录下的所有子目录
   - 识别包含 `skill.md` 或 `index.md` 文件的目录作为有效技能
   - 解析技能元数据（name、description、version等）

2. **元数据解析**
   - 读取技能文件头部的 YAML frontmatter
   - 提取必要字段：`name`、`description`
   - 可选字段：`version`、`author`、`dependencies`、`tags`

3. **技能验证**
   - 检查技能名称是否符合命名规范（仅字母、数字、下划线、连字符）
   - 验证描述字段是否完整
   - 检查依赖项是否满足

### 2. 发现流程步骤

```
1. 启动扫描 → 2. 遍历技能目录 → 3. 解析技能文件
     ↓                                    ↓
6. 生成技能列表 ← 5. 验证通过 ← 4. 提取元数据
```

### 3. 技能索引缓存

- 发现的技能信息会被缓存以提升性能
- 缓存位置：`.trae/cache/skills_index.json`
- 缓存更新时机：技能注册/删除时自动刷新

## 外部技能调用流程

### 1. 调用方式

外部技能可通过以下方式调用：

1. **直接名称调用**
   ```
   使用 global-chinese 技能处理中文响应
   ```

2. **功能匹配调用**
   ```
   我需要创建一个新技能
   （系统自动匹配 skill-creator 技能）
   ```

3. **显式指定调用**
   ```
   @skill-creator 帮我创建一个数据处理技能
   ```

### 2. 调用流程

```
用户请求 → 技能匹配器 → 技能加载器 → 技能执行器 → 结果返回
              ↓              ↓              ↓
         匹配最佳技能    加载技能上下文    执行技能指令
```

### 3. 调用参数传递

- **上下文传递**：当前对话上下文自动传递给技能
- **参数提取**：从用户请求中提取关键参数
- **结果处理**：技能执行结果整合到当前对话

### 4. 调用示例

```markdown
用户：帮我设计一个用户登录界面

系统：匹配到 ui-ux-pro-max 技能
      加载技能上下文...
      执行技能指令...
      返回设计方案...
```

## 外部技能注册流程

### 1. 注册方式

#### 方式一：手动创建

1. 在 `.trae/skills/` 目录下创建技能文件夹
2. 创建 `skill.md` 文件，包含以下结构：

```markdown
---
name: skill-name
description: 技能描述
version: 1.0.0
author: 作者名称
tags: [tag1, tag2]
---

# 技能名称

## 技能说明
[详细描述技能功能和用途]

## 使用场景
[描述适用场景]

## 执行指令
[具体的执行步骤和指令]
```

### 方式二：使用 skill-creator 技能

```
请求 skill-creator 创建新技能
→ 提供技能名称和描述
→ 确认技能功能范围
→ 自动生成技能文件
```

### 2. 注册流程步骤

```
1. 创建技能文件 → 2. 编写元数据 → 3. 编写技能内容
                                          ↓
6. 注册完成 ← 5. 加入索引 ← 4. 验证技能格式
```

### 3. 注册验证

- 检查必填字段是否完整
- 验证技能名称唯一性
- 检查依赖技能是否存在
- 验证指令格式正确性

### 4. 技能模板

```markdown
---
name: my-skill
description: 我的自定义技能
version: 1.0.0
---

# 我的自定义技能

## 技能说明
详细描述技能的功能和用途。

## 使用场景
- 场景1：描述
- 场景2：描述

## 执行指令

### 步骤1：准备工作
[具体操作说明]

### 步骤2：执行主体
[具体操作说明]

### 步骤3：结果验证
[具体操作说明]
```

## 外部技能删除流程

### 1. 删除方式

#### 方式一：手动删除

1. 定位技能目录：`.trae/skills/{skill-name}/`
2. 删除整个技能文件夹
3. 清理技能索引缓存

#### 方式二：请求删除

```
请求删除指定技能
→ 确认删除操作
→ 执行删除
→ 更新索引
```

### 2. 删除流程步骤

```
1. 确认删除目标 → 2. 检查依赖关系 → 3. 执行删除
                                        ↓
5. 删除完成 ← 4. 更新技能索引
```

### 3. 删除前检查

- **依赖检查**：确认无其他技能依赖此技能
- **使用检查**：确认技能当前未被使用
- **备份建议**：重要技能建议先备份

### 4. 删除后处理

- 更新 `.trae/cache/skills_index.json`
- 清理相关缓存数据
- 记录删除日志（可选）

## 现有外部技能列表

| 技能名称 | 描述 | 主要功能 |
|---------|------|---------|
| `global-chinese` | 中文响应支持 | 提供中文语言响应能力，优化中文输出质量 |
| `mcp-builder` | MCP服务器构建 | 构建和配置 MCP (Model Context Protocol) 服务器 |
| `skill-creator` | 技能创建和优化 | 创建新技能、优化现有技能、生成技能模板 |
| `ui-ux-pro-max` | UI/UX设计支持 | 提供专业的用户界面和用户体验设计指导 |

### 技能详情

#### global-chinese
- **用途**：处理中文响应，确保输出符合中文表达习惯
- **调用场景**：需要中文回复时自动激活
- **特点**：支持简体中文、繁体中文

#### mcp-builder
- **用途**：构建 MCP 服务器，配置协议参数
- **调用场景**：需要创建或配置 MCP 服务时
- **特点**：支持多种 MCP 协议配置

#### skill-creator
- **用途**：创建新技能、优化现有技能
- **调用场景**：需要扩展系统能力时
- **特点**：自动生成技能模板，提供最佳实践

#### ui-ux-pro-max
- **用途**：提供 UI/UX 设计指导
- **调用场景**：界面设计、用户体验优化
- **特点**：支持多种设计框架和规范
