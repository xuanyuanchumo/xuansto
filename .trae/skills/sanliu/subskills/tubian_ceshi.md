# 突变测试子技能

## 概述
通过注入错误验证测试质量，确保测试能有效发现代码缺陷。

## 调用时机
- 兵部执行测试时
- 测试质量评估时

## 突变类型
- 算术运算突变：+ → -, * → /
- 条件突变：> → <, == → !=
- 逻辑突变：&& → ||, ! → (无)
- 返回值突变：return true → return false

## 突变得分计算
```
突变得分 = (被杀死的突变数 / 总突变数) × 100%
```

## 质量标准
- 突变得分 ≥ 80%: 测试质量良好
- 突变得分 60-80%: 测试质量一般，需改进
- 突变得分 < 60%: 测试质量不足，需重新生成

## 输出物
- 突变测试报告
- 存活突变列表
- 测试改进建议
