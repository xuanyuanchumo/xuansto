# 人工确认子技能

## 概述
在高风险决策点设置人工确认门禁，确保关键变更经人类审批。

## 调用时机
- AI准备执行高风险操作时
- 流水线到达人工门禁阶段时

## 高风险操作类型
| 类型 | 说明 | 风险等级 |
|------|------|----------|
| dependency | 引入新依赖 | medium |
| schema | 修改数据库Schema | high |
| api | 开放外部接口 | high |
| security | 修改安全相关代码 | critical |

## 确认流程
1. AI生成变更提案
2. 系统暂停自动化流程
3. 人类审批（确认/修改/拒绝）
4. 记录审批结果
5. 继续或终止流程

## 输出物
- 变更提案
- 审批记录
