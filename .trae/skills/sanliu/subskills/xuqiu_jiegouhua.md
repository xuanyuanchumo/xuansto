# 需求结构化子技能

## 概述
将自然语言需求强制转化为结构化格式，确保需求理解准确、可追溯。

## 调用时机
- 中书省接收用户需求时
- 需求变更时

## 结构化输出格式

### 1. 用户故事 + 验收标准（Gherkin格式）
```gherkin
Feature: [功能名称]
  As a [角色]
  I want to [功能描述]
  So that [业务价值]

  Scenario: [场景名称]
    Given [前置条件]
    When [触发操作]
    Then [预期结果]
```

### 2. 功能点列表
| 功能点 | 输入 | 输出 | 异常处理 | 优先级 |
|--------|------|------|----------|--------|
| ... | ... | ... | ... | ... |

### 3. 数据模型与状态变更图
- 实体定义
- 关系图
- 状态机

## 输出物
- 结构化需求文档
- 需求追踪ID列表
