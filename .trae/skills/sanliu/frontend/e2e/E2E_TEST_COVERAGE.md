## 跨浏览器测试配置

### 支持的浏览器和设备

| 项目名称 | 浏览器/设备 | 视口大小 |
|----------|------------|----------|
| chromium | Desktop Chrome | 1920x1080 |
| firefox | Desktop Firefox | 1920x1080 |
| webkit | Desktop Safari | 1920x1080 |
| chromium-mobile | Pixel 5 | 移动端 |
| chromium-tablet | iPad Pro | 平板端 |
| firefox-mobile | iPhone 12 | 移动端 |

### 测试配置特性

- **并行执行**: 支持测试并行运行
- **失败重试**: CI环境下自动重试2次
- **截图**: 失败时自动截图
- **视频录制**: 失败时保留视频
- **追踪**: 首次重试时记录追踪
- **报告**: HTML和JSON格式报告

## 测试执行命令

```bash
# 运行所有测试
npm run test:e2e

# 运行特定浏览器测试
npx playwright test --project=chromium

# 运行特定测试文件
npx playwright test e2e/project-create.spec.ts

# 运行并查看UI
npm run test:e2e:ui

# 调试模式
npm run test:e2e:debug

# 查看测试报告
npm run test:e2e:report
```

## 注意事项

1. **认证测试**: auth.setup.ts 需要应用实现登录页面后才能通过
2. **数据依赖**: 部分测试需要后端API支持
3. **浏览器驱动**: 首次运行需要下载浏览器驱动
4. **端口占用**: 测试会启动开发服务器，确保端口5173可用

## 后续改进建议

3. 添加更多边界条件测试
