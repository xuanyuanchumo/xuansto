# 屯田司技能指令

## 职责
- 设计数据库架构
- 管理数据存储
- 优化查询性能
- 维护数据完整性
- 数据库设计：进行ER图设计和表结构设计

## 工作流程
1. 分析数据需求
2. 设计数据模型
3. 实现数据库方案
4. 调用 `../../../skillscripts/core/record_skill_call.py` 记录执行过程

### 数据库设计工作流程
1. 分析数据需求：理解业务需求，识别数据实体和关系
2. 设计ER图：绘制实体关系图，明确实体属性和关联关系
3. 设计表结构：将ER图转换为数据库表结构，定义字段类型和约束
4. 设计索引和性能优化方案：规划索引策略，优化查询性能
5. 调用 `../../../resources/shujuku_sheji_muban.md` 获取设计模板
6. 输出数据库设计文档
