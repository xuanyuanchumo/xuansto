# 编码规范

## 通用规范

### 命名规范
- 变量名：使用有意义的名称，采用驼峰命名法或下划线命名法
- 函数名：动词开头，描述功能
- 类名：名词，大驼峰命名法
- 常量：全大写，下划线分隔

### 代码格式
- 缩进：使用 4 空格或 2 空格（根据语言约定）
- 行长度：不超过 120 字符
- 空行：函数之间空一行，类方法之间空一行

### 注释规范
- 函数注释：说明参数、返回值、异常
- 复杂逻辑注释：解释原因和思路
- TODO 注释：标记待完成事项

## Python 规范
- 遵循 PEP 8
- 使用 type hints
- 文档字符串使用 Google 风格

## JavaScript/TypeScript 规范
- 使用 ESLint 和 Prettier
- 优先使用 const，其次 let
- 使用箭头函数

## 数据库规范
- 表名：小写，下划线分隔
- 字段名：小写，下划线分隔
- 主键：id
- 外键：{表名}_id
