# SDD 规范模板

本文档提供软件设计文档（Software Design Document）的标准化模板，包含实体定义、接口契约、业务规则、约束条件和验收标准的规范格式。

## 一、规范文档结构说明

### 1.1 文档结构

一份完整的 SDD 文档应包含以下核心部分：

```
SDD 文档结构
├── 1. 概述
│   ├── 文档目的
│   ├── 系统范围
│   └── 术语定义
├── 2. 系统架构
│   ├── 整体架构
│   ├── 技术选型
│   └── 部署架构
├── 3. 实体定义
│   ├── 核心实体
│   ├── 实体关系
│   └── 数据字典
├── 4. 接口契约
│   ├── API 接口
│   ├── 内部接口
│   └── 外部接口
├── 5. 业务规则
│   ├── 业务逻辑
│   ├── 计算规则
│   └── 状态流转
├── 6. 约束条件
│   ├── 业务约束
│   ├── 技术约束
│   └── 安全约束
├── 7. 验收标准
│   ├── 功能验收
│   ├── 性能验收
│   └── 安全验收
└── 8. 附录
    ├── 变更记录
    └── 参考文档
```

### 1.2 文档编写原则

| 原则 | 说明 |
|------|------|
| 完整性 | 覆盖所有设计要素，无遗漏 |
| 一致性 | 术语、格式、编号保持统一 |
| 可追溯性 | 每个设计要素可追溯到需求 |
| 可验证性 | 设计内容可通过测试验证 |
| 可维护性 | 结构清晰，便于更新维护 |

### 4.2 业务规则示例

### BR001 订单金额计算规则

| 属性 | 说明 |
|------|------|
| **规则编号** | BR-001 |
| **规则名称** | 订单金额计算 |
| **规则类型** | 计算规则 |
| **所属模块** | 订单模块 |
| **优先级** | 高 |
| **规则描述** | 根据订单商品明细、优惠活动、运费规则计算订单最终支付金额 |
| **生效条件** | 订单创建或更新时触发 |

#### 规则条件

| 序号 | 条件名称 | 条件表达式 | 说明 |
|------|----------|------------|------|
| 1 | 商品总价 | SUM(商品单价 × 商品数量) | 所有商品小计之和 |
| 2 | 优惠金额 | 优惠规则计算结果 | 根据优惠活动计算 |
| 3 | 运费金额 | 运费规则计算结果 | 根据配送规则计算 |
| 4 | 会员折扣 | 用户会员等级折扣率 | VIP用户享受折扣 |

#### 规则动作

| 序号 | 动作名称 | 动作类型 | 动作内容 | 说明 |
|------|----------|----------|----------|------|
| 1 | 计算商品总价 | 计算 | 商品总价 = Σ(单价 × 数量) | 遍历订单明细 |
| 2 | 应用会员折扣 | 计算 | 折后金额 = 商品总价 × 会员折扣率 | VIP用户折扣 |
| 3 | 计算优惠金额 | 计算 | 根据优惠规则计算 | 满减、优惠券等 |
| 4 | 计算运费 | 计算 | 根据运费规则计算 | 满额包邮判断 |
| 5 | 计算最终金额 | 计算 | 最终金额 = 折后金额 - 优惠金额 + 运费 | 订单应付金额 |

#### 计算公式

```
订单实付金额 = MAX(0, 商品总价 × 会员折扣率 - 优惠金额) + 运费金额

其中：
- 商品总价 = Σ(商品单价 × 商品数量)
- 会员折扣率 = 根据会员等级确定（普通用户：1.0，VIP：0.95，SVIP：0.9）
- 优惠金额 = MIN(满减金额, 优惠券金额) + 其他优惠
- 运费金额 = 商品总价 >= 免运费门槛 ? 0 : 基础运费
```

#### 异常处理

| 异常场景 | 处理方式 | 错误码 | 错误信息 |
|----------|----------|--------|----------|
| 商品价格为负数 | 中断计算，返回错误 | 20001 | 商品价格异常 |
| 优惠金额超过商品总价 | 优惠金额设为商品总价 | - | 最多全额优惠 |
| 运费规则未配置 | 使用默认运费 | - | 应用默认运费规则 |

### CT001 用户密码安全约束

| 属性 | 说明 |
|------|------|
| **约束编号** | CT-001 |
| **约束名称** | 用户密码安全约束 |
| **约束类型** | 安全约束 |
| **约束范围** | 实体级 |
| **所属模块** | 用户管理模块 |
| **约束描述** | 用户密码必须满足安全强度要求，防止弱密码导致的安全风险 |
| **生效时间** | 用户注册、密码修改时 |

#### 约束规则

| 序号 | 规则名称 | 规则表达式 | 错误提示 | 说明 |
|------|----------|------------|----------|------|
| 1 | 最小长度 | length(password) >= 8 | 密码长度不能少于8位 | 确保基本强度 |
| 2 | 最大长度 | length(password) <= 32 | 密码长度不能超过32位 | 防止超长输入 |
| 3 | 包含数字 | password =~ /[0-9]/ | 密码必须包含数字 | 增加复杂度 |
| 4 | 包含小写字母 | password =~ /[a-z]/ | 密码必须包含小写字母 | 增加复杂度 |
| 5 | 包含大写字母 | password =~ /[A-Z]/ | 密码必须包含大写字母 | 增加复杂度 |
| 6 | 包含特殊字符 | password =~ /[!@#$%^&*]/ | 密码必须包含特殊字符 | 增加复杂度 |
| 7 | 禁止常见密码 | password NOT IN common_passwords | 密码过于简单，请设置更复杂的密码 | 防止弱密码 |
| 8 | 禁止与用户名相同 | password != username | 密码不能与用户名相同 | 防止猜测攻击 |

#### 验证方式

| 验证时机 | 验证方法 | 失败处理 | 说明 |
|----------|----------|----------|------|
| 用户注册 | 前端实时验证 + 后端二次验证 | 返回错误提示，阻止提交 | 双重保障 |
| 密码修改 | 前端实时验证 + 后端二次验证 | 返回错误提示，阻止提交 | 双重保障 |
| 密码重置 | 后端验证 | 返回错误提示，阻止重置 | 安全优先 |

| 要素类型 | 要素名称 | 关联说明 |
|----------|----------|----------|
| 接口 | API002-用户注册 | 注册时验证密码强度 |
| 接口 | API005-修改密码 | 修改时验证密码强度 |
