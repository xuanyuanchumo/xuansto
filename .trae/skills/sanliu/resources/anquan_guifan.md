# 安全规范

## 认证与授权

### 密码安全
- 使用强密码策略
- 密码加密存储（bcrypt, argon2）
- 不明文存储密码

### Token 安全
- 使用 JWT 进行认证
- 设置合理的过期时间
- 使用 HTTPS 传输

### 权限控制
- 最小权限原则
- 基于角色的访问控制（RBAC）
- 资源级别的权限检查

## 输入验证

### SQL 注入防护
- 使用参数化查询
- 不拼接 SQL 语句
- 使用 ORM 框架

### XSS 防护
- 输出编码
- CSP 策略
- 输入过滤

### CSRF 防护
- 使用 CSRF Token
- SameSite Cookie

## 数据安全

### 敏感数据
- 加密存储
- 传输加密
- 日志脱敏

### API 安全
- 速率限制
- 请求验证
- 错误信息不暴露敏感信息
