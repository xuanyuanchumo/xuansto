## 📝 附录

### A. 验证工具使用方法

```bash
# 验证单个文档
python skillscripts/utils/skill_doc_path_validator.py validate \
  --file subskills/architecture_overview.md

# 验证整个目录
python skillscripts/utils/skill_doc_path_validator.py validate \
  --dir subskills/

# 自动修复（预览模式）
python skillscripts/utils/skill_doc_path_validator.py fix \
  --files subskills/*.md --dry-run

# 自动修复（实际执行）
python skillscripts/utils/skill_doc_path_validator.py fix \
  --files subskills/*.md

# 导出验证报告
python skillscripts/utils/skill_doc_path_validator.py extract \
  --dir subskills/ --format json --output path_report.json
```

### B. PathConfigCenter 健康检查

```bash
# 初始化配置
python skillscripts/core/path_config_center.py --init

# 全面验证
python skillscripts/core/path_config_center.py --validate

# 健康检查
python skillscripts/core/path_config_center.py --health-check

# 生成报告
python skillscripts/core/path_config_center.py --export-report \
  --output reports/path_health_report.md
```
